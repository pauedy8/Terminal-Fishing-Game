This game is made IN SCRATCH <https://scratch.mit.edu/> .
Using Turbowarp's Packager <https://packager.turbowarp.org/> , it was possible to convert it to a .zip file and deploy it to the web using Cloudflare Workers <https://www.cloudflare.com/products/workers/> .

To play the game, go to https://terminal-fishing-game.pauedy8.workers.dev/ .

It features support for both mobile and desktop devices.
Instructions are present inside the game.
